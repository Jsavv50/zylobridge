# Phase 96 Browse Jobs visual findings

## Desktop
The `/jobs` route renders inside the existing authenticated shell with a clear professional-marketplace hero, aligned search controls, horizontally stable discovery views, a desktop filter rail, and action links for job alerts and posting. Loading skeletons preserve the card grid geometry while real jobs resolve.

## Mobile
At 390px wide, the global header, stacked search controls, horizontally scrollable discovery views, mobile Filters trigger, job-alert link, Post a job action, and single-column loading cards render without visible horizontal page overflow. The desktop filter rail is hidden below the breakpoint and remains available through the dialog trigger.

## Data integrity
The captures show honest loading states because no live job records were available in the preview session. No fabricated jobs, employer metrics, match scores, reviews, ratings, or activity were introduced.
